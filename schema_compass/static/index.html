What should the metadata files contain?

One row per column. Header names are flexible; these are recognized automatically:

Table name (required)table_name, table_physical_name, table; optionally with database/catalog and schema columns
Column name (required)column_name, column_physical_name, field_name
Table business name / descriptiontable_logical_name, data_product · table_description, table_comment
Column business namecolumn_logical_name, business_name, attribute_name, business_term
Column descriptioncolumn_description, description, definition, comment
Data type / lengthdata_type, datatype, full_data_type · length, character_maximum_length
Platformplatform (SNOWFLAKE or DATABRICKS); otherwise the platform chosen at upload

Tip: export straight from INFORMATION_SCHEMA.COLUMNS in Snowflake or Databricks, then add business names and descriptions from your data dictionary. Descriptions improve matching the most.
